### SolveGrid: free statistics calculators for thesis research

[solvegrid.online](https://solvegrid.online) helps students plan, run, and report the statistics in a thesis or survey, all free and in the browser.

Plan your study with the [power analysis calculator](https://solvegrid.online/power-analysis-calculator) and [sample size calculator](https://solvegrid.online/sample-size-calculator). Check questionnaires with [Cronbach's alpha](https://solvegrid.online/cronbach-alpha-calculator) and [Likert scale analysis](https://solvegrid.online/likert-scale-calculator). Run a [t-test](https://solvegrid.online/t-test-calculator), [one-way ANOVA](https://solvegrid.online/one-way-anova-calculator), [chi-square test](https://solvegrid.online/chi-square-calculator), [correlation](https://solvegrid.online/correlation-calculator) or [linear regression](https://solvegrid.online/linear-regression-calculator), and not sure which one? Read [which statistical test should I use](https://solvegrid.online/guides/choose-a-statistical-test).

Built with Next.js and TypeScript; results are verified against SciPy and G*Power.
